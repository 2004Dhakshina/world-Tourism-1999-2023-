#  World Tourism Data Analysis (1999–2023)

## 📌 Project Overview

This project analyzes **25 years (1999–2023)** of global tourism data to uncover trends in international tourism receipts, tourist arrivals, and tourism's contribution to GDP. Using Python for data cleaning, exploratory data analysis (EDA), feature engineering, and visualization, the project provides valuable insights into the economic impact of tourism across countries.

The analysis highlights tourism growth patterns, country-wise performance, economic dependency on tourism, and the effects of global events such as the COVID-19 pandemic.



##  Objectives

- Analyze global tourism trends from 1999 to 2023.
- Compare tourism receipts and tourist arrivals across countries.
- Measure tourism's contribution to national GDP.
- Identify countries with the highest tourism revenue per visitor.
- Explore relationships between tourism and economic indicators.
- Create informative visualizations for data-driven insights.


## Dataset

##  Key Insights

- Countries such as Qatar, Luxembourg, and Switzerland generate high tourism revenue per visitor.
- Island economies like Maldives and Seychelles depend heavily on tourism for GDP.
- Global tourism experienced significant declines during the COVID-19 pandemic (2020–2021), followed by recovery in 2022–2023.
- Tourism receipts generally increase with tourist arrivals, although economic impact varies across countries.
- High-income countries maintain strong tourism revenue through premium tourism experiences.
